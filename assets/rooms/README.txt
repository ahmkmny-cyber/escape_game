# assets/rooms — ضع صور الغرف هنا (1280x720 PNG/JPG)

اللعبة تدعم صور خارجية تلقائياً. لو الملف موجود يُستخدم،
ولو مش موجود تُرسم خلفية إجرائية مؤقتة (procedural fallback).

الأسماء المطلوبة (Room 01 شغال الآن، 02 و 03 للتوسعة):

- room01_server.png   ← غرفة السيرفر (Kill_User)
- room02_clinic.png   ← عيادة د. راغب
- room03_orphanage.png← دار النور (ملجأ)

مواصفات الصورة:
- المقاس: 1280x720 (16:9)، صيغة PNG أو JPG
- ستايل غامق: أسود/أحمر داكن، تباين عالٍ، تفاصيل عند الحواف قليلة
  (النقاط التفاعلية Hotspots تُرسم فوق الصورة)
- الحجم: أقل من 2MB للصورة لسرعة التحميل

مصادر مجانية مرخّصة (CC0 — استخدام تجاري مسموح):
1. Horror Interior Backgrounds (100+ صورة: معمل، مستشفى، غرف آلات)
   · الأفضل لمشروعك: machine room ← room01، hospital ← room02، house ← room03
2. صفحة itch.io للأصول المجانية (ابحث: horror backgrounds free)
3. OpenGameArt (ابحث: spooky backgrounds / horror hallway)
